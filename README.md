 💬 LogiTalk

**LogiTalk** — це мережевий месенджер (чат) на Python, створений для обміну повідомленнями в реальному часі.

## ✨ Основний функціонал
* Підключення до сервера та обмін текстовими повідомленнями.
* Зручний графічний інтерфейс користувача.
* Підтримка роботи кількох користувачів одночасно.

## 🛠 Використані технології
* **Мова програмування:** Python 3
* **Бібліотеки:** `socket`, `threading`, `customtkinter` / `tkinter` *(залиште ті, які використовували ви)*

## 🚀 Як запустити програму
1. Завантажте архів із програмою у розділі **Releases** праворуч.
2. Розпакуйте архів у зручну папку.
3. Запустіть файл `LogiTalk.exe` (або `main.exe`).
